协方差矩阵、相关矩阵与 PCA：一份基础知识笔记

在数据分析、机器学习和科研中，经常会遇到几个概念：数据矩阵 X、协方差矩阵、相关矩阵和 PCA。它们经常一起出现，但初学时很容易混淆。

这篇笔记把它们放在同一个框架里：先看数据如何表示，再看二阶统计量如何描述“哪些维度一起变化”，最后解释 PCA 为什么等价于对协方差矩阵做特征分解。

1. 数据矩阵 X 是什么？

设数据矩阵为：

XinR^{D x T}

其中：

  • D 是特征维度数；
  • T 是样本数；
  • 每一列通常表示一个样本；
  • 每一行通常表示一个特征维度。

例如，如果有 3 个特征、100 个样本，那么：

XinR^{3 x 100}

直接看 X 可以看到每个样本的数值，但如果我们关心的是“不同维度是否一起变化”或者“数据主要沿哪些方向变化”，就需要看二阶统计量。

2. 协方差矩阵是什么？

两个随机变量 X_i 和 X_j 的协方差可以写成：

Cov(X_i, X_j)=E[(X_i - mu_i)(X_j - mu_j)]

直觉是：

  • 如果 X_i 大时 X_j 也往往大，协方差为正；
  • 如果 X_i 大时 X_j 往往小，协方差为负；
  • 如果两者没有明显线性共同变化，协方差接近 0。

对一个 D 维随机向量 x，协方差矩阵是：

Sigma=Cov(x) = E[(x - mu)(x - mu)^T]

它是一个 D x D 矩阵。对角元是每个维度自己的方差，非对角元是两个不同维度之间的协方差。

可以粗略写成：

所以协方差矩阵描述的是：

各个维度之间如何共同波动。

如果实际拿到的是样本矩阵，通常先中心化：

X_c=X - mean(X)

样本协方差矩阵常写作：

Sigmaapprox(1 / T) X_c X_c^T

有时分母会写成 T - 1，这取决于采用总体估计还是无偏样本估计。

3. 相关矩阵是什么？

协方差受量纲和尺度影响很大。例如身高用厘米计，体重用公斤计，数值尺度不同会影响协方差大小。为了比较“结构上的相关强弱”，常引入相关系数：

Corr(X_i, X_j)=Cov(X_i, X_j) / (sigma_i sigma_j)

把所有维度之间的相关系数组成矩阵，就得到相关矩阵：

R=Corr(x)

相关矩阵有几个常见性质：

  • 对角元恒为 1；
  • 非对角元在 [-1, 1] 之间；
  • 去除了尺度差异，更适合比较“相关强弱”。

一句话区分：

协方差矩阵保留“大小”，相关矩阵强调“结构”。

4. 什么时候看协方差，什么时候看相关矩阵？

更适合看协方差矩阵的情况：

  • 各个维度量纲一致；
  • 你关心真实方差和能量分布；
  • 你想解释“每个方向有多少方差”。

更适合看相关矩阵的情况：

  • 不同维度量纲不同；
  • 不同维度方差差异很大；
  • 你主要关心结构相关性，而不是绝对尺度。

在实际分析中，两者经常都看：用相关矩阵看变量之间的关联结构，用协方差谱看全局主方向。

5. PCA 到底在做什么？

PCA 的目标是：

找到数据中变化最大的方向，并用尽可能少的几个方向解释大部分数据变化。

更具体地说，PCA 寻找一组正交方向，使得：

  • 第一个方向上的投影方差最大；
  • 第二个方向在与第一个方向正交的条件下投影方差最大；
  • 后面的方向依次类推。

这些方向就是主成分方向，也就是协方差矩阵的特征向量。

假设单位方向向量为 u，数据点 x 投影到这个方向上的值为：

projection=u^T x

这个投影的方差为：

Var(u^T x)=u^T Sigma u

所以 PCA 的第一个方向就是在 ||u|| = 1 的约束下最大化 u^T Sigma u。这个优化问题的解就是协方差矩阵最大特征值对应的特征向量。

因此：

  • 特征向量给出主成分方向；
  • 特征值给出该方向上的方差大小。

6. 特征值谱应该怎么读？

如果协方差矩阵的特征值为：

lambda_1>=lambda_2 >= ... >= lambda_D

那么：

  • lambda_i 表示第 i 个主成分方向上的方差；
  • lambda_i / sum_j lambda_j 表示第 i 个方向解释的方差比例。

如果前几个特征值特别大，说明数据主要沿少数几个方向变化。如果所有特征值差不多，说明数据在各个方向上比较均匀。

在嗅觉建模里，一个很大的第一主成分可能意味着所有 ORN 一起变强，例如总浓度轴或共同背景响应。

7. 和去相关、白化有什么关系？

PCA 不只是降维工具，也常被用来理解去相关。

如果把数据投影到协方差矩阵的特征向量方向上，得到：

z=U^T x

那么 z 的协方差矩阵是对角的：

Cov(z)=Lambda

这叫去相关：不同主成分之间协方差为 0。

如果进一步除以每个方向的标准差：

y_i=z_i / sqrt(lambda_i)

那么：

Cov(y)=I

这叫白化。

8. 总结

可以把这几个概念串起来：

  1. 数据矩阵 X 存储样本。
  2. 协方差矩阵 Sigma 描述不同维度如何一起变化。
  3. 相关矩阵 R 是标准化后的协方差结构。
  4. PCA 是对协方差矩阵做特征分解。
  5. 特征向量是主成分方向。
  6. 特征值是对应方向的方差大小。
  7. 大特征值表示数据中存在主导变化方向。
  8. 去相关是把协方差矩阵变成对角形式。
  9. 白化是进一步把对角方差归一化成 1。

最短的一句话是：

PCA 是用协方差矩阵的特征向量作为新坐标轴，用特征值衡量每个新方向的重要性。
