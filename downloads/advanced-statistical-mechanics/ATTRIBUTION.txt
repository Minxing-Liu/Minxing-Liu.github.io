Advanced Statistical Mechanics review materials

The baseline lecture-note PDF and reference-sheet PDF in this folder refer to
the public Muatyz/review-sheet repository:

https://github.com/Muatyz/review-sheet/tree/main/%E9%AB%98%E7%AD%89%E7%BB%9F%E8%AE%A1%E7%89%A9%E7%90%86

These baseline materials should not be presented as original work by Minxing
Liu. The website page marks them as reference/baseline materials. Later video
notes, rewritten explanations, and compressed exam sheets should be marked
separately as original review work.

No explicit LICENSE file was found in the referenced repository during this
setup pass, so the original TeX source is linked rather than fully vendored in
this public website repository.
