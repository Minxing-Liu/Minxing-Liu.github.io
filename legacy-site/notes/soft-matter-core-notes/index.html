Suggested Review Order

  1. Start with Introduction for the shared language: k_B T, mesoscopic scale, entropy, and fluctuations.
  2. Read Fluid dynamics and Brownian Motion together to connect low-Reynolds-number flow, damping, and diffusion.
  3. Use Elasticity, Polymers, and Liquid Crystals for solid deformation, chain conformation, and orientational order.
  4. Use Soft Matter Phases and Interfaces/Membranes for phase behavior, self-assembly, surfaces, and curved membranes.
