Thermodynamics and Statistical Physics undergraduate notes

This folder contains an original expanded review note written for Minxing
Liu's Advanced Statistical Mechanics preparation.

Course outline source:
https://www.bilibili.com/video/BV1gW5u6UEML
Title: "(已完结) 热力学与统计物理-汪志诚版"
Uploader: B站物院

The public Bilibili API exposed the video title, uploader, part list, and p=2
chapter points (1.1, 1.2, 1.3, 1.4). The public HTML subtitle field and
player API returned empty subtitle lists in this run, so these TeX notes are
not a transcript.

Reference scope checks:
- Higher Education Press public book page for Wang Zhicheng's Thermodynamics
  and Statistical Physics, 6th edition.
- Higher Education Press public book page for the paired study guide.
- Public USTC thermodynamics/statistical physics courseware pages, especially
  for ensemble-theory coverage.

The TeX project layout is inspired by Muatyz/review-sheet, but the full
Muatyz TeX source is not vendored here.
